\section{Dynamic PCA-KF}\label{sec:dynamicfk}
This applies the previous projection chaining apporach to the PCA-KF algorithm. The algorithm is given as follows:
\begin{enumerate}
    \item \textbf{Predict:}
    \begin{enumerate}
        \item $\bm{P}_{t|t-1} = \bm{P}_{t-1|t-1}+\bm{Q}_{t-1|t-1}$
        \item $\bm{\beta}_{t|t-1}' = \bm{\beta}_{t-1|t-1}'$
    \end{enumerate}
    \item \textbf{Project (if not first iteration):}
    \begin{enumerate}
        \item Acquire the new PCA loadings $\bm{U}_t$.
        \item Acquire the pushforward map: $\bm{V}_t=\bm{U}_{t-1}^T\bm{U}_t$
        \item $\bm{P}_{t|t-1}\leftarrow \bm{V}_t^T\bm{P}_{t|t-1}\bm{V}_t$
        \item $\bm{Q}_{t|t-1}\leftarrow \bm{V}_t^T\bm{Q}_{t|t-1}\bm{V}_t$
        \item $\bm{\beta}_{t|t-1}' \leftarrow \bm{\beta}_{t|t-1}'\bm{V}_t$
        \item $\bm{z}_t\leftarrow \bm{z}_{t}\bm{V}_t$
        \item $\bm{C}_t \leftarrow \bm{C}_t \bm{V}_t$; keep track of the accumulated projection.
    \end{enumerate}
    \item \textbf{Update:}
    \begin{enumerate}
        \item $\delta_t=y_t-\bm{\beta}_{t|t-1}'^T\bm{z}_t$
        \item $S_t= \bm{z}_t^T \bm{P}_{t|t-1}\bm{z}_t + R$
        \item $\bm{K}_t = S_t^{-1}\bm{P}_{t|t-1}\bm{z}_t$
        \item $\bm{\beta}_{t|t}' \leftarrow \bm{\beta}_{t|t-1}' + \delta_t\bm{K}_t$
        \item $\bm{\beta}_{t|t} \leftarrow \bm{\beta}_{t|t}' \bm{C}_t^T$; This is the native $\RR^p$ state estimate.
        \item $\bm{P}_{t|t} \leftarrow (I-\bm{K}_t \bm{z}_t^T)\bm{P}_{t|t-1}(I-\bm{K}_t \bm{z}_t^T)^T+R\bm{K}_t\bm{K}_t^T$: Joseph Update
    \end{enumerate}
\end{enumerate} 
We note that the predict and project steps can be swapped to no effect. The predict and update steps are generic to the KF algorithm when using the Joseph form of the update. We use Joseph form due to enhanced numerical accuracy compared to simpler forms of the update step \cite{Zanetti_DeMars_2013}.
