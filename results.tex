\section{Results}
Here we present some simulation results to test the speed and accuracy of the PCA-KF model. In addition, we provide a result which illustrates how `stale' a static PCA estimate can get when the data is subjected to the covariance rotation as described in Section \ref{sec:rotcov}.
\subsection{Dynamic Projection Tests}
First we present a simulation result with the following hyperparamters:
\begin{itemize}
    \item $(n,n_{burn},p)=(2500,400,200)$, where $n$ is the number of observations, $p$ is the state dimension, and $n_{burn}$ is the number of observations used to initialise PCA.
    \item Initial PCA proportion of variance retained (target): $0.80$.
    \item Maximum angle increment (in radians) $\theta=0.005$, or, $\frac{2\pi}{\theta}\approx 1257$.
    \item $\mathrm{Var}(u_t) = 10^{-2}$
    \item $\veps_t$ construction scale parameter is $10^{-2}$
    \item $x_t$ construction scale parameter is $10^{-2}$
\end{itemize}
We fix an initial PCA rotation $L$, then at time $t$ (of the non-burn data), we find the proportion of variance explained by $L$ of the true covarinace $\Sigma_t$ as: $\frac{\mathrm{tr}(L^T\Sigma_t L)}{\mathrm{tr}(\Sigma_t)}$.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{figures/propvar.png}
    \caption{Proportion of variance retained by method.}
    \label{fig:propvar}
\end{figure}
We can observe from Figure \ref{fig:propvar} that the explained variance of the initial $q$ eigenvectors of the true covariance matrix drops sharply. Indeed, past roughly $1000$ iterations, the proportion of variance plateaus at $\sim 0.33$. This suggests the need to update our representations as we iterate through the algorithm. 
\subsection{Dynamic Filter}
% We observe from Figure \ref{fig:propvar} that the Chained approach is generally more performant than with the fixed projection, however, it is not always better. Note that our projection chaining does not assume anything about the rotation structure; it just cares that the loadings are changing over time. One can entertain the idea that if a rotation structure is assumed, then all that is needed is to estimate the angle step in each plane, then in theory we circumvent the information loss issue. However, the rotation structure does not have an immediate real world application, so there is no grounds to even assume this when chaining projections.
Now, we provide a simulation result for the full PCA-KF algorithm with the following hyperparamters:
\begin{itemize}
    \item $(n,n_{burn},p)=(2500,500,200)$
    \item Initial PCA proportion of variance retained (target): $0.90$.
    \item Angle increment (in radians) $\theta=0.0002$, to prevent excessive shrinkage of our estimate.
    \item $\mathrm{Var}(z_t) = 10^{-2}$
    \item $\veps_t$ construction scale parameter is $10^{-2}$
    \item $x_t$ construction scale parameter is $10^{-2}$
\end{itemize}
